## Which Vice City product does a search result identify?

Look for the complete title, edition, platform and publisher. A result containing Vice City might refer to the original game, the version in the Definitive Edition collection, an official manual or commentary about one of those products. The shared name does not establish identical software.

For a reference sheet, give each edition its own row. Record the source URL beside it and attach platform-specific details only to the row they describe. This prevents a search snippet for a later collection from being copied into a requirements table for an older installation.

The same method applies when a video or screenshot appears without context. A familiar location or character can suggest the title, but the edition and platform still need to be established. Visual resemblance is not a complete software identifier.

## What does a manual establish about controls?

An official manual documents the product and platform named on it. A controller diagram in a manual for one console edition should not automatically be treated as the keyboard layout for a PC edition or the touch interface of a mobile edition.

## How should hardware requirements be read?

Start with the edition and platform selected in the official listing. A requirements table for the PC Definitive Edition collection is not automatically a requirements table for the original PC release, a console version or a mobile port.

Keep Minimum, Recommended and Observed performance in separate fields. A published requirement identifies a stated compatibility condition; a benchmark records an observation made under particular hardware, software and settings. One should not be presented as the other.

This guide does not copy a current hardware-shopping recommendation from a dated snippet. Use the applicable official product listing and support material for the actual version, then compare the device's configuration against the named fields.

For a classroom task, provide two fictional requirement tables and two fictional device records. Ask students to match the correct table to the correct product before comparing specifications. The first step tests source applicability; the second tests the technical comparison itself.

## Why do storage size and memory need separate columns?

Persistent storage holds installed files, while working memory serves a different role during operation. A value in a disk-space field should not be copied into a RAM field merely because both are expressed with familiar data-size units.

Use a fictional example: a product record lists 30 storage units for files and 8 memory units for working memory. A device having 40 free storage units does not, by that fact alone, establish its working-memory capacity. The quantities refer to different resources.

Likewise, an image file's size and a game's installed size are different records. A small promotional screenshot does not reveal the amount of data required to install a product or the space needed while an update is processed.

For an ICT worksheet, ask students to label Processor, Graphics hardware, Working memory and Storage in a supplied device description. Then identify which source field each value should be compared with. Keeping categories aligned is more useful than simply comparing the biggest numbers.

## How can students analyse atmosphere without inventing a review?

An atmosphere analysis should identify the material actually examined. A trailer, official screenshot and complete playthrough provide different evidence. Useful observations can concern a colour palette, the placement of signs, a visible building style or the way a promotional image directs attention. An interpretation can then explain the effect those features suggest, while acknowledging that another viewer may read them differently.

## How should music be discussed in a media exercise?

This approach leaves room for detailed discussion while keeping it tied to the available evidence. A confident description of an unheard track is less useful than an accurate account of the sound and image the student actually examined.

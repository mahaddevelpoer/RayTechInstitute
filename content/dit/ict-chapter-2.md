## Easy topic-wise notes

## 2.1 The Motherboard

The motherboard is the main printed circuit board that connects the principal components of a computer. It provides electrical connections, mounting locations and communication pathways for components such as the processor, memory and expansion devices. A case holds the system; the motherboard connects its parts. Neither the case nor the motherboard alone is the complete computer.

A typical desktop motherboard contains a processor socket or a soldered processor, memory slots, expansion slots, storage connectors, power connectors and interfaces for external devices. The exact arrangement depends on the model. A socket accepts a compatible processor; a memory slot accepts a supported memory module. A physically similar connector is not sufficient evidence that two components are compatible. Processor support can depend on socket, chipset, firmware and power design, while memory support depends on generation, module type and capacity limits.

Buses and interconnects carry data, addresses and control signals between components. In an introductory model, data signals carry values, address signals identify a location and control signals coordinate operations. Modern systems use several specialised links rather than one universal shared bus. A chipset supports platform functions; some functions once placed in separate chipset components are now integrated into processors. Board diagrams should therefore be treated as functional illustrations rather than exact layouts for every PC.

Firmware initialises hardware and starts the boot process. Legacy systems are often discussed using the term BIOS; many modern PCs use UEFI firmware. The firmware program is commonly stored in rewritable non-volatile flash. Settings storage is separate from the program itself. A small battery can maintain the real-time clock and, in older designs, battery-backed configuration memory. Consult the exact manufacturer's manual before identifying a connector, buying a component or attempting an installation.

### Practical examples

- A technician checks the motherboard support list before selecting a replacement processor.
- RAM modules fit supported memory slots; a PCIe network card uses an expansion slot.
- A motherboard manual identifies the correct front-panel and power connectors.

### Common mistakes

- The motherboard is not the CPU: it connects the CPU with other components.
- Do not force a connector or assume that physical fit proves full compatibility.
- Firmware code and configuration settings are not the same thing.

### Quick revision

- The motherboard is the main circuit board.
- It connects processing, memory, expansion and storage interfaces.
- Sockets and slots must match supported components.
- Data, address and control signals have different roles.
- Modern firmware is commonly stored in flash.
- Use the exact model's manual for physical identification.

## 2.2 Processor and the Machine Cycle

The processor, or central processing unit, executes program instructions. Its arithmetic logic unit performs arithmetic operations and logical comparisons. Its control unit coordinates instruction processing, while registers provide very small, fast working locations inside the processor. These are functional explanations; the detailed internal organisation differs across processor designs.

A simplified machine cycle is fetch, decode, execute and store or write back. During fetch, the processor obtains the next instruction from the memory hierarchy. Decode determines the required operation and its operands. Execute performs the requested work, which may involve arithmetic, a comparison, a transfer or a change in program flow. Write back places an applicable result in a register or memory location. Not every instruction writes a result to main memory, and modern processors can overlap the work of several instructions. The model is a teaching sequence, not a claim that every instruction always takes four clock cycles.

The system clock provides timing for processor operations. Frequency is measured in hertz, or cycles per second. One gigahertz is one billion cycles per second. A clock cycle is not the same as a complete instruction: an instruction may involve several operations, and modern processors can process parts of multiple instructions concurrently.

When comparing PC processors, examine the workload, architecture, core and thread counts, cache, clock behaviour, power requirements, cooling and platform compatibility. A higher GHz number alone does not prove that a processor is faster for every task. A newer design with a lower clock frequency can perform more useful work for a particular workload. Several cores help only when the software and workload can use them effectively. Compare relevant measurements under comparable conditions rather than using one specification as a universal speed score.

### Practical examples

- For an addition instruction, the processor obtains the instruction, determines that addition is needed, calculates the result and places it in the required destination.
- A 3 GHz clock describes three billion clock cycles per second, not necessarily three billion completed instructions.
- A video-encoding workload may benefit from more usable cores; another task may depend more heavily on single-thread performance.

### Common mistakes

- The ALU and control unit have different roles.
- Do not equate one clock cycle with one complete instruction.
- The highest clock speed or core count does not guarantee the best result in every application.

### Quick revision

- The CPU executes instructions.
- The ALU performs arithmetic and logical operations.
- The control unit coordinates operations.
- Use fetch, decode, execute and write back as a simplified sequence.
- GHz measures billions of clock cycles per second.
- Compare processors using the relevant workload and compatible platform.

## 2.3 Memory Bits Bytes and Addressing

Memory stores values and instructions used by a computer. A bit is a binary digit with two possible values, normally written as 0 and 1. A byte contains eight bits. Capacity describes how much can be stored; transfer rate describes how much data can move per unit of time. Uppercase B commonly means bytes and lowercase b means bits. Always check the stated units before calculating.

In common decimal storage notation, 1 kB is 1,000 bytes and 1 MB is 1,000,000 bytes. Binary prefixes remove ambiguity: 1 KiB is 1,024 bytes and 1 MiB is 1,048,576 bytes. An exam question or textbook may use KB informally for a binary quantity. State the convention being used instead of silently mixing decimal and binary values. For example, 16 bits equal 2 bytes, and 2 KiB equal 2,048 bytes.

Memory addressing identifies locations. In a byte-addressable teaching model, each address selects one byte. If there are n independent address bits and all combinations are usable, there are 2 to the power n distinct addresses. Thus eight address bits identify 256 locations, which hold 256 bytes in a byte-addressable model. This is not a claim that an 8-bit data value always represents a 256-byte memory capacity. Address width, data width and available memory are different ideas.

RAM provides working memory and ordinary main RAM is volatile. ROM describes read-only or read-mostly non-volatile memory in introductory classifications; it is not simply another name for RAM that has been saved. Cache keeps copies of frequently needed instructions or data close to processing and is typically smaller and faster than main RAM. Cache reduces average access time, but it does not replace main memory or permanent file storage.

Flash is electrically rewritable non-volatile memory used in devices such as USB storage, SSDs and firmware chips. CMOS is a semiconductor technology; the phrase CMOS memory traditionally refers to small battery-backed RAM used for configuration settings. That legacy memory is not inherently non-volatile merely because a battery supports it. Modern systems may store settings in non-volatile memory. Distinguish firmware code, configuration settings, the real-time clock and the battery rather than treating them as one object.

### Practical examples

- A file of 16 bytes contains 128 bits, excluding any separate metadata or transmission overhead.
- An idealised byte-addressable memory with 10 address bits has 1,024 addressable byte locations.
- RAM holds a document while it is edited; saving writes a persistent copy to storage, while cache supports faster access during processing.

### Common mistakes

- Do not confuse bits with bytes or capacity with data rate.
- Use 1,024 for KiB and state any informal KB convention.
- CMOS technology, a battery, firmware and stored settings are different concepts.
- A larger cache does not make a CPU universally faster for every task.

### Quick revision

- One byte equals eight bits.
- KiB and MiB are explicit binary units.
- Addresses identify locations, not the values held there.
- Ordinary main RAM is volatile.
- ROM and flash retain information without continuous power.
- Cache normally holds copies for fast access.
- Legacy CMOS settings RAM is kept alive by a battery.

## 2.4 Expansion Slots Adapter Cards and Drive Bays

An expansion slot is a motherboard interface used to connect a compatible expansion card. An adapter card adds or extends a function such as networking, graphics or sound. A drive bay is a mounting space in a computer case for a suitable drive. The expansion slot provides an electrical connection, while the bay primarily provides a physical location.

PCI Express, commonly abbreviated PCIe, is a widely used expansion interface. Cards and slots can have different physical sizes and lane configurations. A longer-looking slot does not by itself prove how many lanes are electrically connected. Check the motherboard manual for supported configurations, sharing restrictions and compatibility. Older computers may contain legacy PCI or AGP interfaces; these names are not interchangeable with PCIe.

A graphics card can provide graphics processing and display outputs. A network adapter provides a network interface, and a sound card supports audio functions. Many computers already integrate these functions on the motherboard or processor, so a separate card is not always required. The monitor's cable connects to an external display port, not directly to a bare internal expansion slot.

A traditional desktop case may provide 3.5-inch or 2.5-inch drive mounting positions and, on some designs, 5.25-inch bays for optical drives. Storage also needs compatible data and power connections where applicable. Some M.2 devices mount directly on a supported motherboard connector and do not use a conventional drive bay. M.2 describes a form factor and connector family; it does not guarantee that every device uses the same storage protocol. Plan upgrades by checking the case, motherboard, interface, power and clearance together. Practical identification can use diagrams or a disconnected training system under supervision; never force a card or work inside a powered computer.

### Practical examples

- A compatible PCIe Wi-Fi card adds wireless networking to a desktop.
- A 2.5-inch SATA SSD needs a suitable mounting position plus compatible data and power connections.
- A motherboard-mounted M.2 SSD does not need a conventional front-access drive bay.

### Common mistakes

- A drive bay is not an expansion slot.
- Integrated networking does not require an extra network card merely to exist.
- M.2 does not by itself identify the storage protocol.
- Mechanical fit alone is not a complete compatibility check.

### Quick revision

- Slots connect cards electrically.
- Adapter cards add or extend functions.
- Drive bays mount compatible devices in the case.
- PCIe is distinct from legacy PCI and AGP.
- Check lanes, clearance, power and motherboard support.
- Some storage devices mount directly on the motherboard.

## 2.5 Ports and Connectors

A port is an interface through which a system communicates with a device or network. A connector is the physical plug or socket used for a connection. A protocol or interface specification defines how communication works. Connector shape, data rate, video capability and supported power are related but separate properties.

USB connects many peripherals and storage devices and can also provide power. Type-A and Type-C describe connector families. A reversible USB-C connector does not guarantee one particular data speed, video mode or charging capability. The device, port and cable must support the required function. Check their specifications instead of assuming that every cable with the same shape behaves identically.

VGA carries analogue video and does not carry normal HDMI-style digital audio. HDMI carries digital video and can carry digital audio when the connected equipment and cable support the intended mode. A passive change of plug shape does not universally convert analogue video into digital video. Some conversions require active electronics. Choose the correct source output and display input.

Audio connectors may provide headphone or speaker output, microphone input or a combined headset connection. Labels and documentation identify their purpose; colour coding alone is not reliable on every device. A common copper Ethernet connection uses an eight-position modular connector often called RJ-45 in PC networking. A similar-looking telephone connector should not be forced into a network socket.

FireWire is the common name associated with IEEE 1394, a legacy high-speed peripheral interface used by some cameras, audio equipment and computers. It is not simply a different spelling of USB. The PBTE syllabus includes older interfaces, so recognise their purpose without assuming they are present on every current computer. Identify the port, select a compatible cable and connect gently; if a plug needs force, stop and check the type and orientation.

### Practical examples

- An HDMI connection can carry a laptop's picture and sound to a compatible display.
- Two USB-C cables can look similar while supporting different data rates or power capabilities.
- An Ethernet cable connects a supported network port; a headphone lead connects an appropriate audio port.

### Common mistakes

- USB-C connector shape is not a promise of one data rate or charging level.
- VGA is analogue video; HDMI is digital video with audio support.
- A plug-shape adapter does not always perform signal conversion.
- FireWire and USB are different interface families.

### Quick revision

- Separate the physical connector from its supported functions.
- USB supports peripheral connections and applicable power functions.
- USB-C capabilities depend on port, device and cable.
- VGA carries analogue video.
- HDMI carries digital video and supported audio.
- Identify audio and network connectors by purpose and documentation.
- FireWire corresponds to IEEE 1394.

## 2.6 Power Supply

A desktop power supply unit converts incoming mains alternating current into regulated direct-current outputs used by the computer. It supplies electrical power, not program instructions or permanent data storage. The motherboard, processor, drives and some expansion cards have particular power requirements. A laptop often uses an external power adapter and internal power-management circuitry, so its arrangement differs from a standard desktop PSU.

A typical desktop system can use a motherboard main power connector, a separate processor power connector and additional power connections for drives or graphics hardware. Connector standards and arrangements vary. CPU and graphics power leads must not be treated as interchangeable merely because their plugs appear similar. Modular PSU cables are not universally interchangeable across brands or models; a connector that fits the PSU end can still have a different pin assignment. Use manufacturer-approved cables for the exact unit.

The watt rating describes a specified output capability under the unit's rated conditions. A 500 W label does not mean the computer continuously consumes 500 W, and watts are not a processor clock-speed measurement. Select adequate capacity for the actual system, required connectors, expected loads and manufacturer guidance. Efficiency compares useful output power with input power: some input energy is lost, mainly as heat. Efficiency is not the same as output capacity, and no PSU should be described as perfectly efficient.

Cooling and protection support reliable operation. Blocked ventilation or a damaged cable can create faults. A UPS is different from a PSU: a UPS can provide temporary backup power during a mains interruption, while the PSU supplies regulated power to internal components. A surge protector has a different role again and is not automatically a battery backup.

For student practical work, identify a PSU from labels, diagrams or a disconnected training system under qualified supervision. Shut down and disconnect mains power before any permitted internal work, and follow the equipment manual and anti-static procedure. Do not open a PSU enclosure: hazardous stored energy may remain after unplugging. Do not probe mains circuitry, insert objects through ventilation openings or attempt electrical repair as a classroom exercise.

### Practical examples

- A desktop PSU supplies the motherboard and drives with their required DC outputs.
- A machine with a 500 W PSU may draw much less power during a light workload.
- A UPS can keep a computer operating briefly during an outage, but does not replace its internal PSU.

### Common mistakes

- A PSU watt rating is not constant system consumption.
- CPU and graphics power connectors or modular cables are not universally interchangeable.
- A PSU and a UPS are different devices.
- Unplugging does not make opening a PSU safe.

### Quick revision

- A desktop PSU converts mains AC to regulated DC outputs.
- Check power capability and the exact supported connectors.
- Use only approved modular cables for the specific PSU.
- Capacity and efficiency are different measurements.
- A UPS supplies backup power; a PSU powers internal components.
- Keep ventilation clear and use supervised identification tasks.
- Never open the PSU enclosure as a student exercise.

## Solved short questions

### 1. Define a motherboard.

The motherboard is the main printed circuit board that connects and supports the principal computer components and their interfaces.

### 2. Distinguish the ALU from the control unit.

The ALU performs arithmetic and logical operations. The control unit coordinates instruction processing and the required operations.

### 3. Name the simplified machine-cycle stages.

Fetch obtains the instruction, decode identifies the operation, execute performs it and write back stores an applicable result. This does not imply exactly four clock cycles for every instruction.

### 4. What does GHz measure?

Gigahertz measures billions of clock cycles per second. It is not a guarantee of an equal number of completed instructions or a universal performance score.

### 5. Convert 24 bits to bytes and 2 KiB to bytes.

24 divided by 8 equals 3 bytes. Two KiB equal 2 times 1,024, or 2,048 bytes. State the prefix convention used.

### 6. Explain byte-addressable memory.

In a byte-addressable model, each memory address selects one byte location. If n address bits provide every usable combination, they identify 2 to the power n locations.

### 7. Distinguish RAM from flash.

Ordinary main RAM provides volatile working memory. Flash is electrically rewritable non-volatile memory used for persistent storage and firmware.

### 8. Explain the legacy term CMOS memory.

It commonly refers to small battery-backed RAM used for configuration settings. CMOS itself is a semiconductor technology; firmware code, clock circuitry and settings must be distinguished.

### 9. Distinguish an expansion slot from a drive bay.

An expansion slot is an electrical interface for a compatible card. A drive bay is a physical mounting position for a drive, which still needs its appropriate connections.

### 10. Why does USB-C shape not establish every capability?

USB-C specifies a connector family. Data speed, video functions and power support depend on the port, device, cable and their supported specifications.

### 11. Distinguish VGA from HDMI.

VGA is an analogue video interface. HDMI carries digital video and supported digital audio. A change of plug shape does not always provide signal conversion.

### 12. Distinguish a PSU from a UPS.

A desktop PSU converts mains AC into regulated DC for internal components. A UPS can supply temporary backup power during a mains interruption; it does not replace the internal PSU.

## Solved long questions

### 1. Explain the motherboard and its major connections.

**Definition.** The motherboard is the main circuit board, not the complete case or the processor alone.

**Connections.** It provides supported connections for the processor, memory, expansion cards, storage interfaces, power and external peripherals. Their layout depends on the model.

**Communication.** Data signals carry values, address signals identify locations and control signals coordinate operations. Modern systems use several specialised interconnects.

**Compatibility.** Check the exact manual, socket, memory support, firmware requirements, power and clearance. A component's appearance or mechanical fit alone is not proof of compatibility.

### 2. Explain processor operation and compare processor performance sensibly.

**Functional units.** The ALU performs arithmetic and logical operations. The control unit coordinates instruction processing, and registers hold fast working values and state.

**Machine cycle.** Use fetch, decode, execute and write back to describe the basic process. For an addition, obtain and interpret the instruction, perform the addition and place the result in the required destination.

**Timing.** The clock provides timing, measured in cycles per second. GHz means billions of cycles per second, not necessarily an equal number of completed instructions.

**Comparison.** Consider architecture, core and thread counts, cache, workload, power and cooling. Use comparable workload measurements and check motherboard compatibility; one high specification does not establish the best processor for every task.

### 3. Explain memory units and compare RAM ROM cache flash and CMOS settings memory.

**Units and addresses.** One byte is eight bits. KiB means 1,024 bytes. In a byte-addressable model, n independent usable address bits identify 2 to the power n byte locations.

**RAM and ROM.** Ordinary main RAM is volatile working memory. ROM is an introductory category for read-only or read-mostly non-volatile memory.

**Cache and flash.** Cache holds useful copies for fast access near processing. Flash is rewritable non-volatile memory used for persistent storage and firmware.

**CMOS terminology.** CMOS is a technology. The legacy term CMOS memory often means battery-backed settings RAM. Do not equate a battery with firmware storage or treat battery-backed RAM as inherently non-volatile.

**Worked example.** 16 bytes contain 128 bits. Ten address bits identify 1,024 locations when all combinations are usable; that is 1 KiB in the stated byte-addressable model.

### 4. Explain expansion slots adapter cards and drive bays.

**Expansion.** A slot supplies a compatible electrical interface for an adapter card. Graphics, network and audio cards add functions that may also be integrated.

**Interfaces.** PCIe is distinct from legacy PCI and AGP. Check supported lane configuration rather than judging electrical capability solely by slot length.

**Mounting.** A drive bay supports a physical drive. Suitable data, power and mounting connections are still needed. An M.2 device may mount directly on the motherboard.

**Upgrade checks.** Use the exact board and case documentation to check interface, keying, clearance, power and compatibility. Do not force a card or work inside a powered machine.

### 5. Compare the ports listed in the syllabus.

**USB.** USB supports peripherals, data and applicable power functions. Type-C shape alone does not establish data speed, video or charging capability.

**Displays.** VGA carries analogue video. HDMI supports digital video and applicable audio. Analogue/digital conversion can require active electronics.

**Audio and networking.** Audio ports serve defined input/output roles. Common copper Ethernet uses the eight-position modular connector often called RJ-45. Check labels and documentation.

**FireWire and matching.** FireWire is associated with IEEE 1394. Match device, port and cable without force; older syllabus interfaces are not present on every current PC.

### 6. Explain the power supply and appropriate student precautions.

**Function.** A desktop PSU converts mains AC into regulated DC outputs used by internal components. A laptop can use an external adapter and internal power-management circuitry.

**Selection.** Check rated capability, supported connectors, expected load and manufacturer guidance. A watt rating is not constant consumption. Efficiency compares useful output power with input power.

**Connections.** Use the correct CPU, motherboard, drive and graphics connections as specified. Modular cables are not universally interchangeable across PSU models.

**Backup and safety.** A UPS supplies temporary backup and is different from a PSU. Keep ventilation clear. Use supervised identification on a disconnected training system; never open a PSU enclosure because stored energy can remain hazardous.

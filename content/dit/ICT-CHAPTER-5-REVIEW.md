## Accuracy review

The text distinguishes OS, kernel, shell, firmware and driver; stored programs and processes; CPU scheduling and memory management; virtual addresses and storage-backed paging; authentication and authorisation; role categories and actual OS configuration. Desktop systems can be networked, servers can use different interfaces, and Linux distributions can offer GUI and CLI interaction. Windows support is version/edition-dependent; no obsolete release is presented as universally supported.

HDD defragmentation is distinguished from supported SSD TRIM/retrim and other technology-appropriate maintenance. A screen saver is not automatically an access lock. Firewall rules, anti-malware detection, lossless compression and backup are separate functions. Recovery features have different scopes and a sample restore is checked rather than assumed. High CPU activity or temporary improvement after a restart is not treated as a definitive diagnosis.

References include PBTE, Microsoft, the Linux kernel project, Ubuntu and IBM. Practical activities use existing permitted tools, read-only settings observations and non-sensitive sample files. They do not require installing software, deleting user work, changing security settings, forcing optimisation or opening electrical assemblies.

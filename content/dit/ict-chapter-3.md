## Easy topic-wise notes

## 3.1 What Is Input?

Input is data or instructions supplied to a computer for processing. It can be a typed name, a mouse action, a photograph, a recorded sound or a measurement from a sensor. An input device captures a physical action or signal and helps represent it in a form the computer can use. The computer then interprets that input through software.

Data entry and commands serve different purposes. Typing 45 into a marks field supplies a value. Clicking Calculate instructs the program to perform an action. The same keyboard can enter both data and commands. Input is not restricted to human typing: a temperature sensor can report measurements automatically, and a camera can capture a stream of images.

Some physical signals, such as sound pressure, vary continuously. Digital audio capture includes sampling and conversion into numerical values. A microphone captures sound; software may store the recording, analyse it or attempt to recognise words. Capturing a signal and correctly understanding its meaning are separate operations.

Accurate input matters because correct processing rules can still produce an unsuitable result from incorrect data. Validation checks whether input meets defined rules, such as a mark between 0 and 100. Verification checks it against a source or a second entry. A wrong mark of 65 instead of 56 may pass a range check. Neither validation nor automation proves that every entered fact is true. Select the device by the task, accessibility needs, environment and required accuracy.

### Practical examples

- Entering a student name is text input; pressing Save gives a command.
- A sensor records room temperature without a person typing each reading.
- Comparing entered marks with the teacher’s register can reveal a valid-looking error.

### Common mistakes

- Input is not limited to keyboards.
- Capturing sound does not automatically convert it into correct text.
- A range check cannot detect every transcription mistake.

### Quick revision

- Input supplies data or instructions.
- Devices capture actions, images, sound or measurements.
- Software interprets the captured representation.
- Data and commands have different roles.
- Validation checks rules; verification compares with a source.
- Device choice depends on the intended task.

## 3.2 Keyboard and Pointing Devices

A keyboard enters characters and commands through keys. Common groups include alphanumeric keys, function keys, navigation keys, a numeric keypad and modifier keys such as Shift, Ctrl and Alt. Their exact arrangement varies. Shortcuts depend on the operating system and application; a labelled key does not guarantee one universal action in every program.

A pointing device controls a pointer, selects a location or changes an on-screen object. With a mouse, moving the device normally moves the pointer, a click selects or activates according to context, dragging combines holding a button with movement, and the wheel usually scrolls. Optical mice sense movement using light and a sensor; the ball mechanism belongs to older mechanical designs.

A trackball remains in place while the user rotates its exposed ball. This reduces the need to move the whole device across a desk. A touchpad senses finger movement on a surface, commonly on laptops. Gestures and tap-to-click depend on supported hardware and settings. A joystick reports the direction or displacement of a lever and may include buttons. It is suitable for directional control, for example in simulations, rather than long text entry.

Choose input methods by precision, available space and comfort. Keyboard navigation can be useful when a mouse is unsuitable. Pointer speed settings change how physical movement maps to screen movement; a larger setting is not proof of greater accuracy. Keep wrists comfortable, take appropriate breaks and follow cleaning instructions without spraying liquid into equipment.

### Practical examples

- Use a keyboard to enter a paragraph and a mouse to place the insertion point.
- Rotate a trackball while its housing stays still.
- Use a joystick to control direction in a flight simulation.

### Common mistakes

- A trackball moves its ball rather than requiring movement of the whole device.
- A joystick is not the usual choice for typing an essay.
- Keyboard shortcuts and touchpad gestures vary by software and settings.

### Quick revision

- Keyboards enter text and commands.
- Modifiers combine with other keys.
- A mouse is moved across a surface.
- A trackball normally stays stationary.
- A touchpad detects finger movement.
- A joystick provides directional control.

## 3.3 Touch Screen, Pen and Stylus

A touchscreen combines a display with a touch-sensing layer. The display presents output; the sensor reports touch input. A finger selecting a menu is therefore input, while the visible menu is output. A device can perform both roles without making input and output the same operation.

Touch technologies differ. A resistive touchscreen detects pressure that brings conductive layers into contact. A projected capacitive touchscreen detects electrical changes near its sensing grid. Whether gloves, multiple touches or a particular stylus work depends on the specific implementation. Avoid the rule that every touchscreen responds to every object. Gestures such as tapping, swiping and pinching request different actions only when the application supports them.

A stylus is a pen-shaped input tool. A simple passive capacitive stylus acts much like a finger on compatible screens. A supported active pen and digitiser can supply more information, such as pressure, tilt or button actions. These features depend on the pen, device and application working together. Not every stylus requires a battery, and not every pen works with every tablet. A pen tablet may have no display of its own; it maps pen movement to a separate screen. A pen display includes a screen under the writing surface.

Pen input can support drawing, annotation, signatures and handwriting capture. Recognition software may attempt to turn handwriting into text, but it can misread letters. Check the result, especially names and numbers. Calibration or coordinate mapping aligns the reported pen or touch position with the displayed target; it does not add missing pressure hardware. Use only suitable tips and cleaning methods to protect the surface.

### Practical examples

- A student sees a diagram on a touchscreen and taps a label: display output plus touch input.
- A compatible pen lets a drawing application vary stroke width with pressure.
- A handwriting tool misreads a roll number; the student checks the recognised text.

### Common mistakes

- A touchscreen has separate input and output functions.
- Pressure and tilt are supported features, not promises for every stylus.
- A graphics tablet does not always include its own display.

### Quick revision

- Touch sensors report contact positions.
- The screen presents visual output.
- Resistive and capacitive sensing work differently.
- Stylus compatibility must be checked.
- Pen tablets and pen displays differ.
- Handwriting recognition needs review.

## 3.4 Other Types of Input

Game controllers supply actions through buttons, triggers, sticks and sometimes motion sensors. Their vibration function is output, illustrating that one product may contain several input and output components. A digital camera uses an image sensor to capture light as electronic image data. A webcam commonly supplies live video; a camera's megapixel count alone does not determine image quality.

Voice input begins with a microphone and audio capture. Recording preserves sound; speech recognition attempts to turn it into words or commands. Background noise, microphone placement, language and pronunciation can affect the result. Permission to use a microphone or camera should be deliberate, and recordings should be limited to the intended activity.

A scanner captures a document or image. A flatbed supports material on glass; a sheet-fed scanner moves suitable pages through a feeder. Scanning text creates image data. Optical character recognition, or OCR, is a separate interpretation step that can produce searchable or editable text and can make mistakes. Do not confuse OCR with OMR, which detects marked positions on forms, or MICR, which reads characters printed using magnetic ink in suitable systems. A barcode reader captures encoded symbols; an application or database supplies their business meaning.

Biometric systems measure characteristics such as fingerprints, faces or iris patterns. Verification compares a sample with the claimed person's enrolled reference; identification searches for a match among records. Matching is probabilistic and can wrongly match or fail to match. Use authorised demonstrations, protect templates and provide suitable alternatives. A terminal is an access endpoint, for example a checkout or cash-machine interface. It may combine keyboard, reader, screen and printer, so calling the entire terminal input-only is inaccurate.

### Practical examples

- A scanner captures a printed page; OCR then attempts to recognise its words.
- A checkout reader obtains a product code and the application looks up its price.
- A controller accepts button input and may provide vibration feedback.

### Common mistakes

- A scanned page is not automatically accurate editable text.
- Speech recording and speech recognition are different tasks.
- Biometric matches are not infallible and terminal devices can have both roles.

### Quick revision

- Controllers accept buttons, direction and sometimes motion.
- Cameras capture images; microphones capture sound.
- Scanners capture image data.
- OCR recognises text; OMR detects marks.
- Biometric matching can make errors.
- Terminals combine access and interaction functions.

## 3.5 What Is Output?

Output is the result or information a computer delivers after processing. It can be visible text or images, printed pages, sound, or signals that control another device. An output device makes the computer's result available in a usable form. Output is not limited to paper or to something a person can see.

Soft copy is an electronic presentation, such as a result shown on a monitor. Hard copy is a physical record, commonly a printed page. These terms describe the form of the result rather than whether a file is saved. A document displayed on a monitor may have been saved already or may still be unsaved. Printing the page does not automatically create a saved digital copy.

Consider a marks-processing system. Keyboard input supplies marks. Software validates the values and calculates totals. A monitor shows the report, a printer can produce a paper copy and speakers may signal completion. Saving the report to storage retains it for later use. Input, processing, output and storage are distinct functions within the workflow, even if one physical product performs more than one function.

Choose an output method by audience, detail, privacy, accessibility and cost. A large projector can serve a class, while headphones can provide individual audio. Audio feedback can assist users who cannot easily read a screen. Output quality also depends on the source data and settings: a sharper display cannot correct an incorrect calculation. Preview a result and confirm the destination before sending confidential work to a shared printer or screen.

### Practical examples

- A total shown on a monitor is visual output.
- A printed timetable is hard copy; a spoken alert is audio output.
- A teacher previews a result before releasing it to a shared classroom display.

### Common mistakes

- Output is not restricted to printed pages.
- Seeing a document does not prove that it has been saved.
- A high-quality output device cannot correct wrong source data.

### Quick revision

- Output presents or delivers results.
- Visual, printed and audio forms are common.
- Soft copy is electronic presentation.
- Hard copy is a physical record.
- Saving and displaying are separate actions.
- Choose output for audience and access needs.

## 3.6 Display Devices: CRT, LCD and LED

A display presents text, images and video as visual output. Resolution describes the pixel dimensions, such as 1920 by 1080. This example contains 2,073,600 addressable pixel positions. Diagonal screen size, pixel density and resolution are related but different specifications. Two screens with the same resolution can have different physical sizes and pixel densities.

A cathode-ray tube, or CRT, forms an image by directing electron beams toward a phosphor-coated screen. CRT monitors are bulky compared with flat panels and are included here because the syllabus names the technology. Do not open CRT equipment: stored high voltages require qualified servicing. This is a technology comparison, not a recommendation to purchase obsolete equipment.

A liquid-crystal display, or LCD, controls how light passes through liquid-crystal cells and colour filters. In a typical desktop LCD, a backlight supplies illumination. Many products sold as LED monitors are LCD panels with LED backlights, replacing older fluorescent backlighting. LED backlighting does not mean each LCD pixel is itself a light-emitting diode. OLED and direct-view LED are different display technologies; do not apply the LCD-backlight explanation to every product containing the word LED.

Refresh rate in hertz describes how often the display updates per second under a supported mode. Response time describes pixel transitions and is not the same measurement. A higher refresh rate does not increase the pixel dimensions. Scaling changes the apparent size of interface elements and can improve readability. For selection, examine the task, resolution, comfortable size, brightness, contrast, viewing conditions, connection support and accessibility. A compatible connector and supported signal mode are both needed; a cable's shape alone does not guarantee every resolution and refresh combination.

### Practical examples

- 1920 by 1080 describes pixel dimensions, not centimetres or refresh rate.
- An LED-backlit LCD uses LEDs for illumination while liquid crystals modulate the light.
- Increasing interface scaling can make labels easier to read without changing the panel’s physical size.

### Common mistakes

- Screen size, resolution and refresh rate are different properties.
- A common LED monitor is an LCD with an LED backlight, not necessarily a direct-view LED panel.
- Never open CRT equipment for a student identification exercise.

### Quick revision

- CRT uses electron beams and phosphor.
- LCD controls transmitted light.
- Many LED monitors are LED-backlit LCDs.
- Resolution counts pixel dimensions.
- Refresh rate is measured in hertz.
- Response time and refresh rate differ.

## 3.7 Printers and Large-Format Output

A printer produces hard copy. Impact printers strike a ribbon against paper; a dot-matrix printer uses a pattern of pins. Impact mechanisms can serve suitable multipart forms, though noise and output quality depend on the model. Non-impact printers do not use a striking ribbon mechanism. The classification concerns how marks are made, not whether the machine makes any sound or contains moving parts.

An inkjet places small droplets of liquid ink on the medium. Different technologies eject the droplets, so heating is not a universal requirement for all inkjets. A laser printer forms an electrostatic image, applies toner, transfers it to paper and normally fuses it using heat and pressure. Toner is not liquid ink. Fusers and other internal components can be hot; use the model's approved handling and maintenance instructions.

Direct thermal printing darkens specially treated heat-sensitive media and does not require an ink ribbon for that process. Thermal transfer printing uses a heated printhead with a ribbon to transfer material to suitable media. These are different thermal methods. Choose receipt or label media by the supported process and intended durability rather than assuming every thermal print lasts equally long.

A multifunction printer combines functions such as printing, scanning and copying. Its print function is output and its scanner is input. Traditional pen plotters draw lines by moving pens. Many modern large-format printers use inkjet technology for drawings, posters and maps; plotter is not a guarantee of a pen mechanism. Compare supported paper size, print resolution in dots per inch, speed under comparable conditions, colour needs, duplex capability and cost per page. Higher advertised DPI alone does not establish overall quality or running cost. Preview, select the correct pages and print one checked copy before a large batch.

### Practical examples

- A dot-matrix printer can produce suitable multipart forms by impact.
- A laser printer uses toner; an inkjet uses liquid ink.
- A receipt printer may use direct thermal paper, while a label printer may use thermal transfer ribbon.

### Common mistakes

- Non-impact does not mean silent or without moving parts.
- Direct thermal and thermal transfer are different methods.
- A modern device called a plotter is not necessarily a pen plotter.

### Quick revision

- Impact uses a striking ribbon mechanism.
- Inkjet deposits liquid ink droplets.
- Laser printing uses toner and an imaging process.
- Direct thermal uses heat-sensitive media.
- Thermal transfer uses a ribbon.
- Select size, quality, speed and running cost for the task.

## 3.8 Other Output Devices

Speakers and headphones provide audio output by converting electrical signals into sound. Speakers can serve a room; headphones normally serve an individual listener. A microphone performs the reverse role of capturing sound as input. A headset can contain both headphones and a microphone, so classify the component or function named in the question.

Audio suitability depends on clarity, environment and user needs. Start at a comfortable low level, avoid excessive volume and follow the institution's guidance. Headphones reduce sound shared with a room but do not guarantee privacy, and noise cancellation does not mean all external sound is removed. Captions and visual alerts can complement audio for people who cannot readily hear it.

A multimedia projector presents a computer's visual output on a larger surface. The computer supplies image data; the projector forms the projected image. Some models include speakers, networking or touch features, but these are not universal. Readability depends on the projected size, source resolution, focus, ambient light and placement. Lumens describe light output, not pixel dimensions. Do not look into a projection lens or attempt unauthorised lamp servicing.

An interactive whiteboard system combines a visible display or projected image with touch or pen sensing. The image is output; the sensed writing or touch is input. Some systems use a separate projector; others use a flat-panel interactive display. Software can support annotation, saving and collaboration, depending on the product. Confirm that annotations have actually been saved before ending the activity. Choose a classroom setup by audience size, readable contrast, accessibility, room light, connectivity and maintenance requirements rather than by the largest specification alone.

### Practical examples

- A headset plays a lesson through its headphones and captures answers through its microphone.
- A projector shows slides to a whole class.
- A teacher writes on an interactive board; the sensor sends input while the displayed annotation is output.

### Common mistakes

- A microphone is input; speakers and headphones provide output.
- An interactive whiteboard can combine input and output.
- Projector brightness, image resolution and focus are different properties.

### Quick revision

- Speakers and headphones produce sound.
- A headset may include a microphone.
- Projectors enlarge visual presentation.
- Room light affects readability.
- Interactive systems sense touch or pen input.
- Confirm that annotations are saved.

## Solved short questions

### 1. Define input and give two examples.

Input is data or instructions supplied to a computer. Typing a student name supplies text data; selecting Calculate supplies a command. A camera image or sensor measurement is also input.

### 2. Distinguish validation from verification.

Validation checks rules, such as an allowed range. Verification compares entered data with a source or second entry. A wrong mark within the allowed range can pass validation but fail source comparison.

### 3. Compare a mouse and a trackball.

A mouse is normally moved across a surface. A trackball normally stays in place while the user rotates its exposed ball. Both can control a pointer; suitability depends on space, comfort and the task.

### 4. What is a joystick used for?

A joystick reports lever direction or displacement and may include buttons. It is useful for directional control in games and simulations rather than extended text entry.

### 5. Why does a touchscreen have two roles?

The display presents visual output while the touch sensor accepts positions or gestures as input. These separate functions are combined in one physical product.

### 6. Must every stylus support pressure sensitivity?

No. Pressure input requires compatible sensing hardware, a supported pen and software that uses the data. A basic stylus may provide only position input.

### 7. How does scanning differ from OCR?

Scanning captures a page as image data. OCR attempts to recognise characters in that image and can produce searchable or editable text. Recognition errors must be checked against the source.

### 8. What is biometric verification and one limitation?

It compares a measured sample with the claimed person’s enrolled reference. A system can wrongly match or fail to match, so it is not an infallible identity test; authorised handling and suitable alternatives matter.

### 9. Distinguish hard copy and soft copy.

Hard copy is a physical record such as a printed page. Soft copy is electronic presentation such as a screen report. Neither viewing nor printing alone proves the digital file was saved.

### 10. Explain LCD and the common LED-monitor label.

An LCD modulates light using liquid crystals. Many desktop LED monitors are LCD panels illuminated by LED backlights. This is different from claiming that every pixel in every LED-labelled product is a direct light-emitting diode.

### 11. Compare impact and non-impact printers.

Impact printers form marks by striking an inked ribbon against paper, as in dot-matrix printing. Non-impact methods include inkjet, laser and thermal printing. Non-impact does not mean silent or without moving parts.

### 12. How does an interactive whiteboard combine input and output?

Its display or projected image provides output, while its touch or pen sensing supplies input. Annotation and saving depend on supported software, and some systems use flat panels instead of separate projectors.

## Solved long questions

### 1. Explain input, processing, output and saving in a marks system.

**Input.** Enter student identifiers and marks through a keyboard or an authorised import. Device capture and factual accuracy are different: a valid-looking number can still be wrong.

**Checks and processing.** Check ranges and required fields, compare entries with the original record and calculate totals using the stated rules. For three marks 50, 60 and 70, the total is 180 and the mean is 60.

**Output.** Show the total and mean on a monitor. A printer can create a hard-copy report and audio can signal completion. Preview the report and confirm its intended audience.

**Retention.** Save the file to an approved persistent location and check that it can be reopened. Displaying or printing alone does not prove a digital copy was saved.

### 2. Compare keyboard, mouse, trackball, touchpad and joystick.

**Keyboard.** Enters characters, numbers and commands. Explain alphanumeric, navigation, function and modifier keys; shortcut actions depend on the application.

**Mouse and trackball.** A mouse normally moves across a surface. A trackball senses the rotation of its ball while its housing remains stationary. Both provide pointing and selection.

**Touchpad and joystick.** A touchpad senses finger movement and supported gestures, often on a laptop. A joystick gives directional or displacement input, useful in simulations.

**Selection.** Choose a keyboard for long text, an appropriate pointing device for selection and a joystick for directional control. Consider accuracy, available space, comfort and accessibility.

### 3. Describe touch, pen, image and voice input with their limitations.

**Touch and pen.** Touchscreens combine display output with touch input. Pen features such as pressure and tilt require compatible devices and software. A screenless tablet differs from a pen display.

**Images and text.** Cameras capture images and scanners capture physical documents. OCR interprets characters in image data; OMR detects marked positions and MICR reads suitable magnetic-ink characters. These are different methods.

**Voice.** A microphone captures sound. Recording stores audio while speech recognition attempts to interpret words. Noise, language and microphone placement can affect recognition.

**Review and permission.** Check recognised names, numbers and commands against their source. Capture images and audio only for authorised purposes, and protect personal information.

### 4. Compare CRT, LCD and common LED-backlit LCD displays.

**CRT.** Electron beams excite phosphor on a screen. The technology is bulky and contains hazardous high-voltage components, so student observation stays external.

**LCD and backlighting.** Liquid crystals control transmitted light. Typical desktop LCDs use backlighting; many LED monitors are LCD panels with LED illumination. OLED and direct-view LED are separate technologies.

**Specifications.** Resolution gives pixel dimensions: 1920 by 1080 equals 2,073,600 pixel positions. Diagonal size and pixel density differ from this count. Refresh rate describes updates per second; response time describes pixel transitions.

**Practical choice.** Consider readability, scaling, viewing conditions, connections and supported modes. The highest single specification does not automatically suit every classroom or user.

### 5. Explain printer types and choose suitable output for three tasks.

**Mechanisms.** Dot-matrix impact printing strikes a ribbon. Inkjet deposits liquid ink droplets. Laser printing uses electrostatic imaging and toner, normally fixed using heat and pressure. Non-impact describes the marking process rather than absence of noise.

**Thermal and combined functions.** Direct thermal darkens treated media; thermal transfer uses a heated printhead and ribbon. A multifunction unit can scan as input and print as output.

**Task examples.** For suitable multipart forms, consider an appropriate impact printer. For text batches, compare a suitable laser device’s quality and running cost. For large drawings or posters, choose a compatible large-format printer. These are task examples rather than universal purchasing rules.

**Checks.** Confirm media size, colour needs, quality, speed conditions, duplex support and cost per page. Traditional pen plotters and modern large-format inkjets do not share one universal mechanism. Preview and test one copy before a batch.

### 6. Plan an accessible classroom output system and explain its data flow.

**Visual presentation.** Use a suitable monitor or projector so the intended audience can read the material. Set focus, placement, readable text and contrast; account for ambient light. Brightness and resolution describe different properties.

**Audio and alternatives.** Use speakers for shared audio or headphones for individual listening. Add captions or visual alerts where needed. A headset’s microphone is input while its headphones are output.

**Interactive work.** Touch or pen sensors capture actions; software processes them and the display shows the annotation. An interactive flat panel can provide this without a separate projector.

**Saving and handling.** Save and reopen required annotations, check permissions before showing student data, keep audio comfortable and follow equipment instructions. Do not look into a projector lens or open CRT or lamp assemblies for class exercises.

## Practical activities and viva preparation

### Classify a classroom workstation

List available devices without opening equipment. For each, name the exact input or output function. Include a touchscreen, headset or multifunction unit if available; otherwise use a labelled diagram.

**Expected result:** A table with correct component-level roles and at least one explanation of a combined device.

### Compare pointing methods

On a permitted device, enter a short sentence using the keyboard, select a word with a pointer and move an object with dragging. Compare mouse and touchpad if both are available. Record which action was easiest and why.

**Expected result:** A clear distinction between text entry, selection and dragging, with observations rather than unsupported speed claims.

### Capture and check a page

Use an authorised non-personal sample page. Scan or photograph it, then run an already available approved OCR tool if present. Compare five words and two numbers with the original. Do not upload confidential documents.

**Expected result:** An image file, an optional recognised-text sample and a record of any errors; scanning and OCR are distinguished.

### Inspect display and print settings

Record the supported display resolution and refresh rate from settings without forcing an unsupported mode. Preview a one-page practice document and check the printer, page range, orientation and paper size. Print only if authorised.

**Expected result:** Correctly labelled pixel dimensions, hertz and print choices; preview is distinguished from printing and saving.

### Trace an interactive lesson

Draw arrows from pen or touch sensing to software and then to the displayed annotation. If equipment is available, annotate a non-personal example, save it and reopen the file. Otherwise explain the workflow on paper.

**Expected result:** Input, processing, output and retention are shown separately, with a saved-file check when demonstrated.

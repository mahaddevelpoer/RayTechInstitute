# Core-language authoring checklist

The requested minimum is 20 distinct topics per language, 100 in total. A title in this checklist is not a written lesson. Only checked items have authored teaching content; none of these checks means production publication. Complete lesson explanations, three exact worked examples, a guided activity, question-bank review and an assignment must be verified before marking another item written. Frameworks are outside this scope.

Courses group the language tracks. Students still study HTML, CSS, JavaScript, PHP and Python separately. Guided activity completion does not replace a topic test or its 80% assignment threshold.

## Current verified content

Each additional Python unit has three worked examples, documented exact output, prediction/walkthrough/practice blocks, a three-part Understand activity, four question-bank entries and an assignment. These are concise core units (approximately 376 to 492 prose words in the additional lessons), not 2,000-word chapters. The Python foundation also has the animated variable experiment.
